# User Roles

This document defines the roles used in the system and their general responsibilities.

## Super Admin
- Full system access
- Manage all users and roles
- Configure system-wide settings
- Access all projects and data

## HR
- Manage employee records
- Handle onboarding and offboarding
- Manage roles and employment status
- Access HR-related reports

## Project Manager
- Create and manage projects
- Assign team members to projects
- Track project progress and timelines
- View project-level reports

## Team Lead
- Lead and manage assigned team members
- Review code and task submissions
- Assign and prioritize tasks
- Report progress to Project Manager

## Employee / Developer
- Work on assigned tasks
- Submit code and updates
- Collaborate with team members
- View assigned project details

## Intern
- Work on assigned learning or development tasks
- Limited access to projects and systems
- Submit tasks for review
- Access learning resources
